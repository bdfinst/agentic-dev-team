# Convert to prompts

- Use the workflow feature with Sonnet to analyze your sessions from the last 7 days and identify friction points.
- Consolidate the findings using Opus.
- Run another workflow over the last 30 days using Haiku to see if there is anything else that wasn't found in the 7-day analysis.
- Use Fable to propose harness improvements based on those results.
- Use Opus to implement and test them.
