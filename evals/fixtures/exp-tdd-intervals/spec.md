# Feature: merge intervals (intervals.py)
Implement `merge(intervals)` in `intervals.py`. Input is a list of `(start, end)`
tuples (start <= end). Return the minimal sorted list of non-overlapping
intervals covering the same points. Touching intervals (e.g. (1,4) and (4,5))
merge. `merge([])` returns `[]`. Input may be unsorted.
